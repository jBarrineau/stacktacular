# Stacktacular

A cheerful three.js block-stacking game, made to be easy to play on an iPad.

**Play:** https://jbarrineau.github.io/stacktacular/

- **Relaxed** mode: slow and steady, no hearts, never ends (tap 🏁 Finish twice to stop).
- **Challenge** mode: speeds up, 3 hearts — and the tower is **tipsy**: off-centre drops make it lean
  (watch the TILT meter), perfects steady it, dropping on the opposite side earns a COUNTERWEIGHT bonus,
  and if it leans too far… TIMBER!

On an iPad, open the link in Safari, tap **Share → Add to Home Screen** for a full-screen app icon.

Everything is self-contained (no CDNs): three.js r170 is in `vendor/` (MIT license),
and the Bungee and Fredoka fonts are in `fonts/` (SIL Open Font License 1.1, see `fonts/OFL-*.txt`).
